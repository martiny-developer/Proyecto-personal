# 📝 Planificador de Tareas

Aplicación web de una sola página (SPA) para organizar tareas: registrarlas, actualizarlas, filtrarlas y eliminarlas, con persistencia de datos.

Deploy: https://martiny-developer.github.io/Proyecto-personal/

---

## 📌 Descripción

**Problema:** organizar las tareas del día a día de forma simple, sin perderlas al cerrar el navegador.

**Solución:** una SPA que permite gestionar tareas desde una interfaz limpia, con formulario de registro, listado de tareas y almacenamiento persistente.

---

## ✨ Funcionalidades

- ➕ **Crear tareas** con nombre, descripción y fecha.
- ✏️ **Actualizar** la información de una tarea existente.
- 🔍 **Filtrar** las tareas registradas.
- 🗑️ **Eliminar** tareas que ya no necesitas.
- 💾 **Persistencia de datos**: las tareas se conservan al recargar la página.
- 📱 **Diseño responsive** con Bootstrap.

## 🚀 Instalación y uso

No requiere dependencias ni compilación.

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/<tu-usuario>/planificador-de-tareas.git
   cd planificador-de-tareas
   ```

2. **Abrir la aplicación**
   - Abre `index.html` directamente en el navegador, o
   - sírvela con una extensión como Live Server en VS Code.

---

## 🧭 Cómo usarla

1. Escribe el **nombre**, la **descripción** y la **fecha** de la tarea en el formulario *Nueva Tarea*.
2. Pulsa **Agregar tarea**.
3. Consulta, filtra, edita o elimina tus tareas desde la sección **Mis Tareas**.
